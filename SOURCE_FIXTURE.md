# SourceSDK source-side controls
SourceSDK({'a':'owner-a','b':'owner-b'}) supplies the six source consumer ports in CONTRACT.md. Its state remains in the same object when a Pump is discarded. No Pump or archive implementation is included.
The test operator uses deliver_batch(fetch_request,batch,rows,parts=2,order=[1,0,1]) to queue real fragments, finish_fetch to complete delivery, begin_revoke to request transfer, and settle(commit_request,reply=False) to accept a commit while losing its reply. poll_events returns queued finite events. auto_accept=True accepts pending commit/release operations during polling; empty fetches remain pending until the operator completes them. owned/check expose the accepted fact even after a reply was lost. Source deletion removes acknowledged row bodies; immutable batch metadata may remain. Test-operator methods are not consumer ports.
The original demo and legacy tests remain unchanged. The public unittest discovery also checks source fragment hashing, lost replies, irreversible raw release, pending request identity, source-side gap rejection, independent partitions and fencing after release.
